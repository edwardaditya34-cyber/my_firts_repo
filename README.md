# Automated Desktop File Organizer (Python)

A lightweight desktop utility built with Python that automatically sorts cluttered folders into clean, categorized subdirectories in seconds.

## Features
- **One-Click Folder Selection:** Built-in graphical folder picker (`tkinter`)—no manual path editing required.
- **Smart Categorization:** Automatically groups files into `Images`, `Documents`, `Videos`, `Audio`, `Archives`, and `Others`.
- **Safe & Fast:** Uses Python's native `os` and `shutil` modules with zero external dependencies.
- **Standalone Executable Ready:** Can be packaged into a `.exe` file for Windows users without Python installed.

## How to Run
1. Download or clone this repository.
2. Run `python file_organizer.py` in your terminal.
3. Select the target folder from the pop-up window and let the script organize your files automatically.
